# wa-tui

WhatsApp in your terminal: a full-screen chat app plus a scriptable CLI.

```sh
npm i -g wa-tui
wa login    # scan the QR code with WhatsApp on your phone
wa          # open the chat app
```

Update the same way: `npm i -g wa-tui`. wa tells you in its header when
a new version is out. Keep it current, because WhatsApp stops accepting
old versions.

Works on Windows, macOS and Linux (x64 and arm64). Nothing to compile:
npm installs a prebuilt binary for your machine.

Source, issues and the full command list:
https://github.com/INTERDICTOR1/wa-cli

wa-tui is built on [whatsmeow](https://github.com/tulir/whatsmeow) and
continues [codebyoketch/wa-cli](https://github.com/codebyoketch/wa-cli).
It is not affiliated with WhatsApp or Meta.
